# TraxAgent for Claude Code

Ask Claude what your company spends on AI, and ship the fixes, without leaving Claude Code.

- **AI spend in chat**: spend by team, developer, model and API key across Claude, OpenAI, Gemini, Claude Code, Codex and Cursor.
- **Cost fixes you can ship**: TraxAgent ranks fixes in dollars a month; Claude follows the fix steps in your repo and opens a PR.
- **Spend status line**: session cost, 5-hour and weekly limit use, and your spend cap.

Read-only. TraxAgent never sees prompts or outputs.

## Install

```
/plugin marketplace add ccarter01011/traxagent-claude-plugin
/plugin install traxagent@traxagent
```

Then run `/mcp`, pick `traxagent`, choose **Authenticate** and sign in to TraxAgent in your browser. No token to copy. (The MCP server is on TraxAgent's paid plans.)

## Try it

- "What did we spend on AI last week, by team?"
- "Which API key is using the most Opus?"
- "What's the biggest cost fix, and can you ship it here?"
- "Set up the spend status line."
